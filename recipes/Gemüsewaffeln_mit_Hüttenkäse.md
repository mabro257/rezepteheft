# Gemüsewaffeln mit Hüttenkäse

Kategorie: Hauptspeise
Portionen: 2
Quelle: Andechser Natur (andechser-natur.de)
Tags: Schnell, Meal Prep, Frühstück
Zubereitungszeit: 30

## 🛒 Zutaten

> 💡 Ergibt ca. 8 kleine Waffeln – 4 pro Portion. Am besten gelingen sie in einem Mini-Waffeleisen oder einem Eisen für dicke belgische Waffeln.

| Menge | Zutat |
| --- | --- |
| **Teig:** | |
| 1 | Zucchini (klein, ca. 200 g) |
| 1 | Karotte (ca. 90 g) |
| 50 g | Haferflocken (zart) |
| 85 g | Mehl |
| 2 TL | Backpulver |
| 1 | Ei |
| 100 g | Hüttenkäse (körniger Frischkäse) |
| 100 ml | Milch |
| **Gewürze:** | |
| 1 TL | Knoblauchpulver |
| 1 TL | Italienische Kräuter (getrocknet) |
| ½ TL | Paprikapulver |
| ½ TL | Salz |
| 1 Prise | Pfeffer |
| **Zum Einfetten:** | |
| etwas | Butter |

## 👨‍🍳 Zubereitung

1. **Gemüse raspeln:** Zucchini und Karotte fein raspeln, in ein Sieb oder ein sauberes Küchentuch geben und das Wasser kräftig ausdrücken.
2. **Teig anrühren:** Das Gemüse in einer Schüssel mit Haferflocken, Mehl, Backpulver, Ei, Hüttenkäse und Milch zu einem dicken Teig verrühren.
3. **Würzen:** Mit Knoblauchpulver, Italienische Kräuter, Paprikapulver, Salz und Pfeffer würzen und den Teig 5 Minuten quellen lassen.
4. **Waffeleisen vorbereiten:** Das Waffeleisen aufheizen und mit etwas Butter einfetten.
5. **Ausbacken:** Den Teig portionsweise einfüllen und die Waffeln goldbraun und durchgegart ausbacken, bis der Teig aufgebraucht ist.

## 💡 Tipps

- Gut für Meal Prep: Die Waffeln halten sich gekühlt 2–3 Tage und werden im Toaster oder Ofen wieder knusprig.
- Statt der Einzelgewürze passt auch ein fertiges Gewürzsalz für Pizza & Pasta.
- Dazu schmeckt ein Kräuterquark oder Joghurt-Dip; eine Handvoll geriebener Käse im Teig macht sie noch herzhafter.
- Je gründlicher das Gemüse ausgedrückt wird, desto knuspriger werden die Waffeln.
