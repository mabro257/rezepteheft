# Sommerlicher Couscous-Salat

Kategorie: Hauptspeise
Portionen: 4
Quelle: Marry Kotter (marrykotter.de)
Tags: Bowl & Salat, Meal Prep, Orientalisch
Zubereitungszeit: 80

## 🛒 Zutaten

> 💡 Als Hauptgericht mit gebratenem Halloumi und Joghurtsauce, ohne beides eine schnelle Beilage fürs Grillfest. Instant-Couscous verwenden – der wird locker und nicht matschig.

| Menge | Zutat |
| --- | --- |
| **Salat:** | |
| 250 g | Couscous (Instant) |
| 250 ml | Wasser (kochend) |
| ½ | Salatgurke |
| 1 | Paprika |
| 10 | Cherrytomaten |
| 2 | Frühlingszwiebeln |
| nach Bedarf | Minze oder Petersilie (frisch) |
| **Dressing:** | |
| 1 | Zitrone (Saft) |
| 3 EL | Tomatenmark |
| 6 EL | Olivenöl |
| 2 EL | Wasser |
| 2 TL | Harissa (Paste oder Gewürz, alternativ Chili) |
| 1 Zehe | Knoblauch |
| ½ TL | Zucker |
| etwas | Salz und Pfeffer |
| **Joghurtsauce:** | |
| 400 g | Joghurt (griechisch) |
| ½ | Gurke |
| 1 Zehe | Knoblauch |
| 1 Prise | Zucker |
| etwas | Salz und Pfeffer |
| **Dazu (optional):** | |
| 1 Packung | Halloumi (ca. 225 g) |

## 👨‍🍳 Zubereitung

1. **Couscous quellen lassen:** Couscous in eine Schüssel geben, mit dem Wasser übergießen und nach Packungsangabe etwa 5 Minuten quellen lassen.
2. **Dressing:** In einer großen Schüssel den Saft der Zitrone mit Tomatenmark, Olivenöl, Wasser, Harissa, gepresstem Knoblauch, Zucker sowie Salz und Pfeffer verrühren.
3. **Mischen:** Den Couscous mit einer Gabel auflockern, unter das Dressing heben und 5 Minuten abkühlen lassen.
4. **Gemüse untermischen:** Salatgurke, Paprika und Cherrytomaten klein würfeln bzw. vierteln, Frühlingszwiebeln in Ringe schneiden und alles mit den gehackten Kräutern unter den Couscous mischen.
5. **Durchziehen lassen:** Den Salat mindestens 60 Minuten ziehen lassen und vor dem Servieren noch einmal abschmecken.
6. **Joghurtsauce und Halloumi:** Gurke raspeln und mit Joghurt, gepresstem Knoblauch, Zucker, Salz und Pfeffer verrühren. Halloumi in Scheiben schneiden, in einer Pfanne von beiden Seiten goldbraun braten und zum Salat reichen.

## 💡 Tipps

- Der Salat schmeckt am nächsten Tag noch besser und hält sich gekühlt 2–3 Tage – ideal für Meal Prep und als Mitbringsel.
- Die geraspelte Gurke für die Joghurtsauce leicht ausdrücken, sonst wird die Sauce wässrig.
- Statt Halloumi passt gebratener Tofu.
