# Quartals-Quesadillas

Gesundheitswert: 🍰 Genussrezept
Kategorie: Hauptspeise
Portionen: 2
Quelle: Rezeptheft
Tags: Pfannengericht, Schnell
Zubereitungszeit: 20

## 🛒 Zutaten

| Menge | Zutat |
| --- | --- |
| 1 Packung | Uncle Bens Reis Mexican |
| nach Bedarf | Streukäse |
| nach Bedarf | Crème fraîche |
| nach Bedarf | Nachos |
| nach Bedarf | Mais |
| nach Bedarf | Sriracha |
| 2 | Wraps |
| etwas | Öl |

## 👨‍🍳 Zubereitung

1. Reis im Topf erwärmen.
2. Wrap an einer Stelle im Radius einschneiden.
3. Wrap mit allen Zutaten belegen – darauf achten, dass der Käse später außen ist.
4. Wrap Viertel für Viertel einklappen, sodass eine Döner-Form entsteht.
5. In etwas Öl von beiden Seiten anbraten.

## 💡 Tipps

- Der Käse außen sorgt für eine schöne Kruste – nicht weglassen!
- Avocado oder Guacamole als zusätzliche Schicht macht ihn sämiger
- Für mehr Biss: ein paar extra Nachos in die Mitte geben
