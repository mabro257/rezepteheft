# Gemüse-Masala-Bowl mit Spinat-Hirse und Gurken-Joghurt-Dip

Kategorie: Hauptspeise
Portionen: 2
Quelle: HelloFresh (hellofresh.de)
Tags: Schnell, Ofengericht, Bowl & Salat, Orientalisch
Zubereitungszeit: 30

## 🛒 Zutaten

| Menge | Zutat |
| --- | --- |
| **Masala-Gemüse:** | |
| 300 g | Blumenkohl |
| ½ Dose | Kichererbsen (ca. 120 g abgetropft) |
| ½ Zehe | Knoblauch |
| 2 EL | Tikka-Masala-Paste |
| 1 EL | Olivenöl |
| 50 ml | Wasser |
| 10 g | Koriander |
| **Spinat-Hirse:** | |
| 150 g | Hirse |
| 300 ml | Wasser (heiß) |
| 100 g | Babyspinat |
| **Gurken-Joghurt-Dip:** | |
| 1 | Gurke |
| 150 g | Joghurt |
| **Außerdem:** | |
| nach Bedarf | Salz |
| nach Bedarf | Pfeffer |

## 👨‍🍳 Zubereitung

1. **Vorbereiten:** Backofen auf 220 °C Ober-/Unterhitze vorheizen. Blumenkohl in kleine Röschen teilen, Kichererbsen abspülen und abtropfen lassen, Knoblauch schälen.
2. **Gemüse backen:** Blumenkohl und Kichererbsen in einer Schüssel mit Olivenöl, Wasser und Tikka-Masala-Paste vermengen, bis alles rundum überzogen ist. Zusammen mit dem Knoblauch auf einem mit Backpapier belegten Blech verteilen und auf mittlerer Schiene 20 Minuten backen.
3. **Hirse kochen:** Wasser leicht salzen, Hirse in einem Topf damit aufkochen und zugedeckt auf kleinster Stufe 15 Minuten köcheln lassen.
4. **Spinat unterheben:** Topf vom Herd ziehen, Babyspinat auf die Hirse geben und zugedeckt 5 Minuten ziehen lassen. Umrühren und mit Salz und Pfeffer abschmecken.
5. **Dip anrühren:** Gurke grob raspeln, mit dem Joghurt verrühren und mit Salz und Pfeffer würzen. Den gebackenen Knoblauch hineinpressen und unterrühren.
6. **Anrichten:** Koriander hacken, ein paar Blätter zurückbehalten. Den Rest unter das Masala-Gemüse mischen. Spinat-Hirse in Schalen geben, Gemüse und Dip daneben anrichten und mit dem übrigen Koriander bestreuen.

## 💡 Tipps

- Wird die geraspelte Gurke vorher leicht ausgedrückt, bleibt der Dip schön cremig und wässert nicht.
- Statt Hirse passen auch Quinoa, Couscous oder Basmatireis.
- Für eine vegane Bowl einfach Sojajoghurt für den Dip verwenden – die Masala-Paste vorher auf tierische Zutaten prüfen.
