# Erdnusssauce

Gesundheitswert: ⚖️ Ausgewogen
Kategorie: Zutat
Portionen: 4
Quelle: Rezeptheft
Tags: Asiatisch, Schnell, Vegan
Zubereitungszeit: 5

## 🛒 Zutaten

| Menge | Zutat |
| --- | --- |
| 65 g | Erdnussbutter |
| 2 EL | Sojasauce |
| 2 EL | Ahornsirup |
| 2 EL | Essig |
| 1 EL | Knoblauchöl |
| 2 TL | Sriracha |
| 2 EL | Zitronensaft |
| nach Bedarf | Wasser |

## 👨‍🍳 Zubereitung

1. Alle Zutaten mit dem Pürierstab vermengen. Nach Bedarf Wasser hinzufügen für die gewünschte Konsistenz.

## 💡 Tipps

- Für eine Dip-Konsistenz weniger Wasser; für Salatdressing mehr Wasser hinzufügen
- Tahin kann einen Teil der Erdnussbutter ersetzen für ein nussigeres Profil
- Im Kühlschrank hält die Sauce bis zu einer Woche
