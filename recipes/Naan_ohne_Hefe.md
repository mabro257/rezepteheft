# Naan ohne Hefe

Kategorie: Backen
Portionen: 3
Quelle: Kichererb.se (kichererb.se)
Tags: Brot & Teig, Orientalisch, Pfannengericht, Schnell, Vegan
Zubereitungszeit: 25

## 🛒 Zutaten

> 💡 Ergibt 3 Fladen – 1 pro Portion. Lässt sich problemlos verdoppeln.

| Menge | Zutat |
| --- | --- |
| **Teig:** | |
| 130 g | Mehl |
| 1 TL | Backpulver |
| ½ TL | Meersalz |
| 50 g | Sojajoghurt (ungesüßt, oder Naturjoghurt) |
| 50 ml | Wasser |
| **Zum Bestreichen:** | |
| nach Bedarf | Olivenöl (oder geschmolzene Margarine) |

## 👨‍🍳 Zubereitung

1. **Mischen:** Mehl, Backpulver und Meersalz in einer Schüssel vermengen.
2. **Teig kneten:** Sojajoghurt und Wasser zugeben und alles 2–3 Minuten zu einem glatten, weichen Teig verkneten. Klebt er stark, etwas Mehl einarbeiten.
3. **Ausrollen:** Teig dritteln und jedes Stück auf bemehlter Arbeitsfläche dünn zu einem ovalen Fladen ausrollen.
4. **Backen:** Eine beschichtete Pfanne ohne Fett stark erhitzen. Die Fladen nacheinander auf jeder Seite 3 Minuten backen, bis sie Blasen werfen und braune Flecken bekommen.
5. **Bestreichen:** Die warmen Fladen direkt mit Olivenöl bestreichen und sofort servieren.

## 💡 Tipps

- Für Knoblauch-Naan eine gehackte Knoblauchzehe und etwas Petersilie oder Koriander unter das Öl zum Bestreichen rühren.
- Dinkelmehl (Type 630) funktioniert genauso gut wie Weizenmehl.
- Fertige Fladen in ein Küchentuch einschlagen, so bleiben sie weich, bis alle gebacken sind.
- Passt zu Currys, Dals und Eintöpfen.
